# HighGround

A desktop app for managing IDE instances.

## Currently Supported

- VS Code
- Cursor

It is useful if you work with multiple editor instances at the same time.

## What HighGround Does

- Launches IDE instances with specific parameters
- Manages multiple editor windows
- Controls running processes
- Provides access to terminals from one place
- Lets you quickly switch between projects

The goal is to have a single control point instead of managing many separate windows.

## Plugins

HighGround have some pretty useful plugins (more useful than the app itself probably xD).

### Auto Submit Codex

Automatically presses the submit button across multiple editor windows.  
Works even when the windows are minimized.

## Who It’s For

HighGround is useful for developers who:

- Work with multiple projects simultaneously
- Use several VS Code or Cursor instances
- Struggles with constant Submit requests form Codex agent
- Want centralized control over editors and processes
